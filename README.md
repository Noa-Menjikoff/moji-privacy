# Politique de Confidentialité - Moji

**Dernière mise à jour :** 26 avril 2026

L'application **Moji** est engagée dans la protection de votre vie privée. Cette page vous informe de nos politiques concernant la collecte et l'utilisation des données.

## 1. Collecte des données
Pour fonctionner, Moji collecte les informations suivantes via **Google Firebase** :
* **Adresse e-mail :** Utilisée pour l'authentification et la sécurisation de votre compte.
* **Nom d'utilisateur :** Utilisé pour personnaliser votre profil.
* **Données de progression :** Statistiques d'apprentissage, séries (streaks) et mots sauvegardés.

## 2. Utilisation des données
Ces données sont uniquement utilisées pour :
* Vous permettre de synchroniser votre progression sur plusieurs appareils.
* Gérer votre compte utilisateur.

## 3. Services Tiers
Moji utilise **Google Firebase** pour l'authentification (Firebase Auth) et la base de données (Firestore). Ces services traitent vos données conformément à la politique de confidentialité de Google.

## 4. Suppression des données
Conformément à la loi, vous disposez d'un droit total sur vos données :
* Vous pouvez supprimer votre compte et **toutes vos données associées** instantanément via le bouton "Supprimer mon compte" dans les réglages de l'application.

## 5. Contact
Pour toute question, contactez-nous à : mojiapp.contact@gmail.com
